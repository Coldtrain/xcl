# XCL third-party sources

XCL is licensed under **GPL-3.0-only** (`LICENSE`). Below is everything that comes from outside,
together with its license and how it is used. Files that contain logic ported from another project
carry a note in their header about its origin and the date of changes (GPL-3.0 §5 requirement).

| Source | License | What in XCL | How |
|---|---|---|---|
| [AnyPS5](https://github.com/boykopovar/AnyPS5) | GPL-2.0-only upstream; separate permission grants this project GPL-3.0-only relicensing of the incorporated contributions | recompiler (`crates/xcl/src/gpu/recomp/`) – portions of logic marked in the files | port to Rust/HLSL with annotation |
| [SixNG](https://github.com/holdmysocks/SixNG) | GPL-3.0-only | `crates/xcl/src/bc6pack.rs`, `bc6pack_tables.rs`, `bc7pack.rs`, `bc7pack_tables.rs` | BC6H BCPack reconstruction and fitted preset history (commit `087f7ddd0d3a0b4a2acc42e9e78d16e953d4982f`); BC7 BCPack decoder and fitted tables (commit `b57cdb036839c559d60da648925239d25dbb3ee9`); some fitted history entries remain unknown |
| [bcpack-rs](https://github.com/Ahmet-Dedeler/bcpack-rs) / Microsoft silicon-rans | MIT OR Apache-2.0 | `crates/xcl/src/bcpack_rans/`, `bc1pack.rs`, `bc1pack_window.json`, `bc1pack_quad_table.json` | rANS decoder/model tables vendored from bcpack-rs (commit `02a8c4e802800d55b55797a32dbfe8b16d7fc23f`); BC1 decoder and fitted history/index tables adapted from bcpack-rs (commit `61ea9b2a2699625911cddcb44998ae32da05abfe`); model tables originate from Microsoft `silicon-rans` |
| [Dom-in/Leonida](https://github.com/Dom-in/Leonida) | GPL-3.0-only | `crates/xcl/src/bc5pack.rs`, `bc5pack_history.json` | BC5 BCPack block-rebuild algorithm and fitted endpoint-history data adapted from `tools/bcpack.py` and `tools/bcpack_tables.py` (commit `561b65a832218fbb9e6d2effd392a8eef093a3f8`); rANS lane decoder is the existing bcpack-rs/Microsoft silicon-rans port |
| [FFmpeg](https://ffmpeg.org/) | LGPL-2.1+ | XMA1/XMA2 decoder and tables (`crates/xcl/src/hle/xma2/`) – after `libavcodec/wmaprodec.c`, `wmaprodata.h`, `wma.c`, `sinewin_tablegen.h`, `libavutil/float_dsp.c`, `tx_template.c` | port to safe Rust with annotation |
| [AMD Machine-Readable GPU ISA](https://gpuopen.com/machine-readable-isa/) | MIT | `crates/xcl/src/gpu/rdna2_spec.rs` (generated by `scripts/gen_rdna2.py`) | encoding and instruction tables |
| [AMD addrlib](https://gitlab.freedesktop.org/mesa/mesa/-/tree/main/src/amd/addrlib) (Mesa) | MIT | `crates/xcl/src/gpu/tiling_tables.rs` (generated by `scripts/gen_tiling.py` from `gfx10SwizzlePattern.h`); GFX10 mip chain / mip tail layout in `gpu/tiling.rs` (after `Gfx10Lib::ComputeSurfaceInfoMacroTiled`) | swizzle tables; layout logic ported with annotation |
| [LLVM](https://github.com/llvm/llvm-project) | Apache-2.0 WITH LLVM-exception | `tests/data/llvm-amdgpu/*` (test data, not part of the program); GFX10 buffer format values (`UfmtSymbolicGFX10`) in `gpu/recomp/emit.rs` | test vectors; hardware facts |
| [WinDurango](https://github.com/WinDurango/WinDurango) | LGPL-3.0 | no code; d3d12_x.dll export numbers (facts) in `crates/xcl/data/stubdb.toml` | reference only |
| [libHttpClient](https://github.com/microsoft/libHttpClient) | MIT | no code; XTaskQueue/XAsync contract | specification |
| Windows XGameRuntime (`System32\xgameruntime.dll`) | system | class GUIDs and slot order of the GDK thunk protocol in `hle/xgameruntime/api.rs` (facts, determined by analysis); APIs XCL does not implement are forwarded to it at runtime | interoperability; not distributed |
| docs.xbox.com | documentation | signatures, enums, structs written independently | reference |
| Rust crates (`Cargo.lock`) | MIT / BSD-2 / Zlib / Unlicense (or with an MIT alternative) | build dependencies | statically linked |
| [libopus](https://opus-codec.org/) (`opus.dll`) | BSD-3-Clause | Opus decoding where Windows has no `MSOpusDecoder.dll` (Wine): loaded at runtime from `%XCL_OPUS_DIR%` / next to xcl.exe (`hle/opus.rs`) | **not** distributed with XCL |
| DXC (`dxcompiler.dll`, `dxil.dll`) from the Windows SDK | NCSA (dxcompiler) / Microsoft (dxil) | HLSL → DXIL compilation at runtime | loaded from the user's SDK, **not** distributed with XCL |
| Windows system libraries (d3d12, dxgi, xaudio2_9, mfplat, MSOpusDecoder, ole32 …) | system | target APIs | GPL-3.0 §1 "System Libraries" exception |

When adding dependencies: compatible with GPL-3.0-only are MIT, BSD, Zlib, ISC, Unlicense, LGPL-2.1(+),
GPL-2.0(+), MPL-2.0 (via its Secondary License clause). Incompatible: Apache-2.0 without an alternative,
GPL-3.0, LGPL-3.0, AGPL.
